Zelda Ages + Seasons Combined

Les deux Oracle dans une seule ROM, dans la langue de ton choix, fabriquée à partir de tes propres ROMs européennes sur le code de la version américaine. Rien n'est envoyé : tout se passe dans ton navigateur.

1Tes ROMs européennes

Oracle of Ages et Oracle of Seasons, version Europe (En,Fr,De,Es,It). Dépose les deux fichiers ici.

Oracle of Ages (Europe)Manquante
Oracle of Seasons (Europe)Manquante

2Langue du jeu

La traduction officielle de Nintendo, reprise des ROMs européennes.

Bon à savoir : le jeu est construit sur la version américaine (le code du désassemblage oracles-disasm), dans laquelle on remet les textes et images européens. La ROM générée contient donc une seule langue, celle choisie ici, sans menu de langue au démarrage.

3Options

Décoche ce que tu ne veux pas ; l'aperçu montre le résultat. Les corrections de bugs sont toujours incluses.
